# Community Sports Facility Booking Optimizer

Local-first Streamlit dashboard for community sports facility demand, accessibility, capacity, travel and maintenance planning.

## Run
```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
streamlit run app.py
```

Sample data: `data/sample_sports_facility_records.csv`

Features: priority screening, readiness score, zone benchmarking, demand/capacity analytics, accessibility analysis, smart booking matching, rule-based alerts, what-if scenarios and CSV export.
